# rails-6-basic-configuration

A placeholder for a reusable base configuration for new Ruby on Rails 6 projects.

## Status

This repository currently contains only this README. No configuration files have been added yet.

## Intended scope

A starting point for common setup steps on a fresh Rails 6 app, for example:

- Ruby and Rails version pinning
- Database setup
- Webpacker / JavaScript pipeline
- Test setup (RSpec, Capybara, FactoryBot)

For a working Rails 6 example, see [checkwebpack](https://github.com/Salman464/checkwebpack).
